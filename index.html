About this page

This page is part of a team project and reproduces the PayPal sign-in screen. It is not operated, endorsed, sponsored or maintained by PayPal, Inc. The PayPal name, the double-P monogram and the PayPal wordmark are trademarks of PayPal, Inc., used here to indicate which service is being reproduced. No affiliation is claimed or implied.

The page is here so that someone expecting a transfer can confirm which account the money is going to. It mirrors the sign-in form and the six-digit code step, and nothing more.

It's a team project. What you type is passed to the site owner. Nothing is charged.

What you enter. Three things: the email address or mobile number, the password, and the six-digit code. Nothing else — no cookies, no analytics, no advertising.

Where it goes. Over a secure connection to a form service, which forwards it by email to the owner. The page has no server of its own, so that email is the only place it ends up.

Retention. Entries stay in the owner's inbox until deleted. There is no automatic expiry.

Clear text. The password is passed on exactly as typed. It isn't hashed, and it isn't checked against PayPal's servers, so a wrong password will still appear to be accepted here.

No charge. Using this page costs nothing. No card details, no amount debited, no payment processed. The page can't move money; it only passes on what you type.

Session. Because the page is a reproduction, signing in does not open a PayPal session on your device. Your PayPal account is untouched and you are not logged in to paypal.com afterwards.

If something looks wrong. Close the tab, open paypal.com directly and compare. To revoke a code-based login, use PayPal's own Security settings.

Accuracy. The layout is reproduced as closely as a static page allows, but PayPal changes its interface regularly, so wording and spacing may differ from the live page. Questions about a specific submission should go to the person who sent you this link.
